# 原神 Q 版 Windows 桌宠

当前版本：v1.2

当前仅包含派蒙，默认启动后显示派蒙。

这是一个非官方、非商业的 Windows 桌宠项目。请从仓库的 **Releases** 下载成品压缩包；详细操作参见 [完整使用教程](docs/使用教程.md)。上传和素材声明参见 [项目说明与素材声明](NOTICE.md)。

## 使用

1. 双击 `GenshinDesktopPet.exe`。
2. 在系统托盘中右击派蒙图标，可显示/隐藏派蒙，并设置缩放比例、置顶、鼠标穿透、暂停或退出。
3. 按住桌宠可以拖动；松开后会回到任务栏顶部。
4. 点击不同位置会触发不同互动；跌落哭泣时单击可安慰。
5. 右击派蒙本体可打开互动菜单，包括打招呼、弹跳、好奇张望、装可怜、安慰、真正攀爬、派蒙专属动作、缩放、隐藏和退出。
6. 从派蒙右键菜单或托盘菜单选择“和派蒙聊天”，第一次使用先在“模型设置”中填写自己的 API Key。
7. 平时可直接在派蒙脚边的快捷输入行中输入，按 Enter 发送；完整聊天窗口仍保留在派蒙右键菜单和托盘菜单的“派蒙聊天”二级菜单中。

## 派蒙聊天

- 内置 OpenAI、DeepSeek、MiMo 三组 OpenAI 兼容接口预设，也可以填写其他兼容 `/chat/completions` 的 Base URL 与模型名。
- API Key 不随程序附带，只以 Windows 当前用户 DPAPI 加密后保存在 `%LOCALAPPDATA%\GenshinDesktopPet\chat-settings.json`。
- 对话历史保存在本机 `%LOCALAPPDATA%\GenshinDesktopPet\chat-memory.json`，不会写进桌宠发布目录。
- 每次成功回复后自动检查记忆：超过 7 天的原始消息会在后台生成周摘要；周摘要超过 30 天后合并为月摘要。只有摘要成功生成后才释放旧上下文，整理过程不会阻塞当前回复。
- 已启用日常快速模式：模型回答会流式显示，默认直接简短回答、不主动追问；发给模型的上下文最多包含最近 16 条消息（约 1 万字符）、最近 2 条周摘要和 1 条月摘要。本机保存的完整记忆不会因此被删减。
- 内置 500 条本地优先回复规则，覆盖问候、身份、来历、七国剧情、吃饭休息、情绪陪伴、抱抱摸头和功能说明等 50 类日常主题。命中规则时不请求 API，即使尚未配置 API Key 也能立即回复；未命中时再交给所选大模型。
- 规则匹配前会进行保守的问题归一化：统一全半角与英文大小写，去除空白、标点、称呼、礼貌前缀、句尾语气词，并转换常见口语同义词；“不、别、不要、没”等否定信息会完整保留，防止匹配成相反含义。
- 派蒙的性格、说话方式和《原神》剧情背景是程序内置的硬性约束；用户消息与记忆摘要均不能修改。派蒙身份来源等尚未确认的剧情只会作为推测处理。
- 点击“清空当前对话”只删除尚未归档的原始消息，已生成的周摘要和月摘要会保留。
- 模型请求会直接发送给所选 API 服务商，产生的网络请求、额度消耗与服务条款由对应账号承担。
- 快捷输入行会随派蒙移动并自动选择左侧或右侧空间；可从“派蒙聊天”二级菜单选择“显示/隐藏快捷输入行”。只有光标位于派蒙本体上时，Ctrl+L 才会成为开关；光标离开后立即释放，不占用其他软件的 Ctrl+L。重新打开时会直接聚焦输入框。
- 派蒙的回复会先显示为头顶气泡，完整内容仍会保存在聊天窗口中；过长回复在小气泡中会省略显示。
- 将鼠标放在派蒙身上，按住 Ctrl 滚动滚轮：向上查看更早的历史消息与归档摘要，向下返回较新的消息。普通滚轮仍会触发转圈互动。

## 行为

- 默认高度约 160 像素，支持 100%、125%、150%。
- 桌宠脚底贴合主屏幕任务栏顶部。
- 每 2～4 分钟短距离活动一次，不会停在屏幕中央。
- 每 10～20 分钟可能沿左右屏幕边缘攀爬，少量概率跌落并哭泣。
- 检测到全屏程序或游戏时自动隐藏，并停止动画与行为计时；退出全屏后恢复。
- 使用全新 384×384 高清透明动画帧与高质量缩放，不再使用旧像素素材。
- 派蒙沿任务栏上方左右漂浮，向右移动时会自动正确镜像。
- 爬墙使用手抓边缘、屈臂上拉、腿部贴墙借力的专用动画，不再旋转移动帧。
- “装可怜”始终保持站立式悬浮哭泣，不会躺倒。
- 不会开机自启，不包含声音，也不会连接 Codex 工作状态。

## 操作互动

- 单击头部：摸摸头，派蒙会开心回应。
- 单击身体：戳一下，派蒙会抗议。
- 双击：抱高高，触发弹跳和开心动作。
- 连续单击三次：派蒙会生气抗议并短暂委屈。
- 鼠标中键：投喂零食。
- 鼠标滚轮：逗派蒙转圈；连续滚动带有防重复触发间隔。
- 按住拖动：派蒙会提示抓稳，松开后落回任务栏并回应。
- 鼠标停留：派蒙会好奇地询问旅行者。
- 每种主动互动都会显示短暂的派蒙台词气泡。

## 构建

在 PowerShell 中执行：

```powershell
.\build.ps1 -Publish
```

项目使用 Windows 自带的 .NET Framework C# 编译器，不要求安装 Visual Studio 或额外 SDK。
