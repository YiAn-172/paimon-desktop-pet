# 派蒙桌宠 v1.2 使用教程

## 一、下载与启动

1. 打开 GitHub 仓库右侧的 **Releases**。
2. 进入 `v1.2`，下载 `原神Q版桌宠-v1.2.zip`。
3. 将压缩包完整解压到一个普通文件夹，不要直接在压缩包内运行。
4. 双击 `GenshinDesktopPet.exe`。
5. 如果 Windows SmartScreen 提示未知发布者，请先确认文件来自本仓库，再选择“更多信息”→“仍要运行”。当前程序没有购买代码签名证书，因此可能出现该提示。

程序启动后，派蒙会贴着主屏幕任务栏顶部活动；右下角系统托盘会出现桌宠图标。

## 二、基础操作

- 按住派蒙拖动：移动桌宠，松手后会回到任务栏顶部。
- 单击头部：摸摸头。
- 单击身体：戳一下。
- 双击：抱高高。
- 连续单击三次：触发派蒙的生气和委屈反应。
- 鼠标中键：投喂零食。
- 普通滚轮：逗派蒙转圈。
- 右击派蒙：打开互动、动作、缩放、聊天、隐藏和退出菜单。
- 将光标放在派蒙身上并按 `Ctrl+滚轮`：查看历史会话。
- 只有光标位于派蒙本体上时，`Ctrl+L` 才会显示或隐藏快捷输入行。

## 三、聊天方式

### 本地快速回复

程序内置 500 条派蒙日常回复规则，覆盖问候、姓名、来历、七国剧情、饮食、休息、情绪陪伴和互动等话题。输入会先进行保守归一化，例如：

- `派蒙，请问你叫什么呀？`
- `那个，你在干啥呢？`
- `派蒙，你从哪儿来的呀？`

这些问题命中后会在本机直接回答，不需要 API Key、不访问网络，也不消耗模型额度。否定词会保留，避免把“不喜欢”错误识别为“喜欢”。

### 快捷输入行

1. 右击派蒙。
2. 打开“派蒙聊天”子菜单。
3. 选择“显示/隐藏快捷输入行”。
4. 输入内容后按 `Enter` 发送。

快捷输入行会出现在派蒙脚边或旁边。派蒙的回复会逐段显示在头顶气泡中。

### 完整聊天窗口

在派蒙右键菜单或托盘菜单中选择“派蒙聊天”→“打开完整聊天窗口”。完整窗口可以查看当前会话、整理记忆、清空未归档对话和配置模型。

## 四、配置大模型 API

没有命中本地规则的问题，需要配置 OpenAI、DeepSeek、MiMo 或其他兼容 `/chat/completions` 的接口。

1. 打开完整聊天窗口。
2. 点击“模型设置”。
3. 选择服务商，检查 Base URL 和模型名称。
4. 填入你自己的 API Key。
5. 点击“测试连接”。
6. 测试成功后点击“保存”。

建议日常聊天使用服务商提供的轻量或快速模型。程序采用流式输出、短回答和精简请求上下文，以尽快显示第一段回复。

API 请求会产生对应服务商的网络流量和可能的额度费用。程序不会附带或免费提供任何第三方 API Key。

## 五、记忆和隐私

- API Key 使用 Windows DPAPI 加密后保存于 `%LOCALAPPDATA%\GenshinDesktopPet\chat-settings.json`。
- 聊天记录保存于 `%LOCALAPPDATA%\GenshinDesktopPet\chat-memory.json`。
- 7 天前的对话可以生成周摘要，30 天前的周摘要可以合并为月摘要。
- 摘要成功后才会释放已归档原文。
- 点击“清空当前对话”不会删除已经生成的周摘要和月摘要。
- 删除整个 `%LOCALAPPDATA%\GenshinDesktopPet` 文件夹可以清除本机设置、密钥和聊天记忆；执行前请确认不再需要这些数据。
- 上述用户数据不在程序目录中，也不包含在 GitHub 上传版和 Release 压缩包中。

## 六、显示与后台行为

- 默认高度约 160 像素，支持 100%、125%、150% 缩放。
- 仅在当前主屏幕活动。
- 检测到全屏程序或游戏时自动隐藏并暂停活动，退出全屏后恢复。
- 默认不开机自启。
- 托盘菜单可以暂停、隐藏、切换置顶和鼠标穿透。
- 开启鼠标穿透后无法直接点击派蒙，需要从托盘菜单关闭鼠标穿透。

## 七、常见问题

### 双击程序没有反应

检查系统托盘中是否已经存在派蒙图标。程序只允许一个实例运行。

### 无法点击或右击派蒙

从系统托盘菜单确认“鼠标穿透”没有开启。

### 本地规则能回答，但其他问题没有回复

这通常表示尚未配置 API Key，或者模型设置中的 Base URL、模型名称不正确。打开“模型设置”运行连接测试。

### 回复仍然较慢

本地规则应当立即回复。大模型问题的速度仍取决于服务商、所选模型和网络状况，建议换用更轻量的模型。

### 如何彻底退出

右击派蒙或托盘图标，选择“退出桌宠”。只关闭聊天窗口不会退出主程序。

## 八、从源码构建

系统要求：Windows 10/11，并具备 .NET Framework 4.x 编译环境。

在项目根目录打开 PowerShell，执行：

```powershell
.\build.ps1 -Publish
```

构建结果：

- `bin\GenshinDesktopPet.exe`：当前构建程序。
- `portable\`：可直接打包发布的便携目录。

项目使用 Windows 自带的 .NET Framework C# 编译器，不依赖 Visual Studio 或第三方 NuGet 包。
